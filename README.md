# Project 2 Company Nework

Welcome to my **CCNA Networking Projects** repository.

This repository contains networking projects created using **Cisco Packet Tracer** while learning and practicing CCNA concepts.

Each project focuses on different networking concepts such as VLANs, routing, DHCP, DNS, WAN connectivity, and network troubleshooting.

---

## 📂 Projects

### 🔹 Project 1 - Branch Office WAN

A simple enterprise network connecting a **Headquarters (HQ)** with a **Branch Office** using a Serial WAN connection.

**Concepts covered:**

- VLAN Segmentation
- LAN Configuration
- WAN Connectivity
- Router Configuration
- DHCP
- DNS
- Routing
- Network Connectivity Testing

📁 **Project Folder:** `01-Branch-Office-WAN`
